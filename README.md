
This repository contains SystemVerilog designs, testbenches, and C reference models for 
assignments in Northwestern University's COMP\_ENG 387 course.

Also included are utility IPs implemented out of personal interest, including `msb`
( most-significant bit finder ), `div` ( division ), `fifo` ( synchronous/asynchronous FIFOs )
and `gray` ( Gray code ).

The assignment designs that have been significantly optimized after course completion
currently include:

 - hw4-edgedet ( Sobel edge detector )

 - hw7-fft ( fast Fourier transform )
